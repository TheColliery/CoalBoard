# CoalBoard

CoalBoard is a consensus and debate board for hard, error-sensitive tasks. It convenes several independent reviewers in parallel, lets a judge synthesize their findings on verified inputs, and stages any proposed change for a human to approve. Nothing touches a live file until a person signs off.

Install the plugin from the Claude Code marketplace, then run `/coalboard` on a task that deserves a second and third opinion. The full manual lives in the repository README, and every release is listed in its CHANGELOG.
