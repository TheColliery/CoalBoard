# CoalBoard on Antigravity (validated, measured 2026-10-29)

> Loaded ON-DEMAND when running the board on Antigravity. The SKILL.md flow is the same on every platform; this maps the platform-agnostic contract to AG's tools and the caveats. Measured 2026-10-29 with agy 1.4.8 (a self-run headless check, not third-party-audited): the SKILL.md body is 21,128 bytes, under Antigravity's 24,000-byte load, and the mandatory references `references/rails.md` and `references/steps.md` are read on demand; a report-only `/coalboard` load check read them and reached Step 4 with every rail read. The 2026-06-22 validation (Claude Opus 4.6, self-run) predates the 2.8.10 and 2.8.11 bodies (51,244 and 51,554 bytes), which did not fit; 2.9.0 moved the steps and the standing rails into references.
A platform with no read-only/leaf toggle OR no reap tool → fall back to the SKILL's conservative path (fewer workers, sequential, flag UNVERIFIED). AG has both, so the tool mapping above applies.
